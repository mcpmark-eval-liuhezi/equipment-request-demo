# Equipment Request Demo

This repository demonstrates our equipment-request workflow:

1. A requester opens a pull request adding the items they need to a tracked file (`equipment/requests.md`).
2. The approver leaves review comments on each line asking for current Amazon quotes.
3. The requester follows up on the pull request with matched products, exact prices, and ratings.

## File being tracked

- `equipment/requests.md` — the list of items requested for pricing.
